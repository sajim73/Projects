## Interpretation rule
1. `Published`: directly attributable to paper or official artifact.
2. `Reanalyzed`: computed anew from published input data using scripts that can be rerun.
3. `Simulated`: generated by our own explicit model, not a live Redis/WfPatch measurement.
4. `Measured`: obtained from actually executing a system, with logs and environment details.

A report must never describe published, reanalyzed or simulated measurements as independently executed WfPatch results.

## SIGMOD ARI requirements checklist
- Dockerized experiment environment when moderate hardware permits.
- One master script running experiments and producing plots.
- Source code or executable provided.
- README documenting dependencies, hardware, run commands, runtime and excluded figures.
- Fresh-machine end-to-end validation before submission.
- Specialized hardware exception involves access for reviewers and a single runnable master script.
